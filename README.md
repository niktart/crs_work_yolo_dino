# Умная касса: Детекция товаров с помощью open-world моделей компьютерного зрения

> **Исследовательский курсовой проект** — экспериментальный анализ open-world моделей детекции объектов для автоматического распознавания продуктов питания в системах «умной кассы».

## 📋 О проекте

Данный репозиторий содержит код и материалы исследовательского курсового проекта, выполненного в Национальном исследовательском университете «Высшая школа экономики» (Факультет компьютерных наук, программа «Программная инженерия»).

**Цель исследования** — экспериментальный анализ современных open-world моделей детекции объектов (YOLOv8-World и Grounding DINO) на задаче распознавания фруктов, овощей, хлебобулочных изделий и других товаров для систем автоматизации розничной торговли.

**Основные результаты:**
- ✅ Достигнута бизнес-метрика **77.45%** — доля полностью корректно распознанных изображений
- ✅ Скорость инференса **2.67 FPS** на CPU (OpenVINO FP16) — прирост 13% относительно базового PyTorch
- ✅ Адаптация модели к новому классу (манго) за **9 минут** обучения с точностью **94%**
- ✅ Выявлено, что **70.5% ошибок** приходится на путаницу между визуально похожими классами

## 🎯 Постановка задачи

Традиционные модели детекции объектов работают в закрытом множестве классов (closed-world) — они распознают только те категории, на которых были обучены. Для розничной торговли это неприемлемо, так как:

- Ассортимент товаров постоянно обновляется
- Появляются сезонные и акционные товары
- Система должна работать в реальном времени на ограниченном оборудовании (кассовые терминалы)

В рамках проекта исследуются две open-world модели, способные распознавать новые классы без полного переобучения:

| Модель | Архитектура | Параметры | Ключевое преимущество |
|--------|-------------|-----------|----------------------|
| **YOLOv8-World** | Сверточная сеть | ~11 млн | Высокая скорость, эффективный инференс на CPU |
| **Grounding DINO** | Трансформер | ~173 млн | Лучшие zero-shot способности |

## 📊 Набор данных

Для обучения использован объединенный датасет из четырех открытых источников (Roboflow). Все изображения сделаны в реальных условиях — на улице, на кухне, на подносах, в руках.

| Источник | Классы | Количество | Особенности |
|----------|--------|------------|-------------|
| Фрукты | 9 | ~1600 | Высокая плотность объектов, вид сверху |
| Овощи | 15 | ~2100 | Естественное освещение, разная текстура |
| Выпечка | 14 | ~1200 | Вариативность формы и нарезки |
| Прочие товары | 8 | ~500 | Размытые границы (мясо, рыба) |
